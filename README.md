# 闸对

中文名：**闸对** · 前缀 `gatetwin` · 端口 **6500 / 11500**

## 骨架

**刷卡点装载 → 同卡进站出站成对物化 → 缺腿/异向/超时旁路 → 行程账与刷卡点互证**

皮：地铁/公交闸机刷卡。去皮是 **OD 成对管道 + 开腿态 + 旁路 + 行程贯验**，不是票务售票 CRUD、不是乘车码业务页、不是日结封账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6500
# 刷卡流 → 灌「成对样例」→ 看开腿账/行程账 → 再灌「缺腿超时样例」「出站孤儿样例」→ 行程贯验
# 出站孤儿 → 补录闸开闸 → 选补录进站站 → 经闸补录 → 行程贯验
```

## 补录闸（`出站无进补录闸`）

已旁路的「出站孤儿」只可经补录闸补录成行程，禁止绕过旁路终态直接改已成对。

- **写闸硬约束**：闸开/关与虚进写入同成败；单事务 `BEGIN IMMEDIATE` 内写虚进刷卡点、开腿、成对、关旁路、记审计，失败整体回滚。
- **口径 `manual_stop`**（全局唯一）：必须以请求体指定补录进站站，且须在「站点」权威表可解；缺参/未知站拒绝；**禁止自动首站**。
- **结果与旁路关闭同票**：行程落账与旁路状态 `已补录` 同事务提交；并发补录同一旁路绝不双落。
- **只读接口**：`GET /api/补录闸`（闸开关/口径）、`GET /api/补录闸/预演`（闸开关/旁路编号/虚进站/行程/拒绝/valid）。

| 接口 | 说明 |
| --- | --- |
| `GET /api/补录闸` | 当前闸开关与口径 |
| `GET /api/补录闸/预演?旁路编号=&出站事件编号=&补录站点键=` | 只读推演，不写数据 |
| `POST /api/补录闸/开关` `{闸态:开/关}` | 切闸（记补录闸流水） |
| `POST /api/补录闸/补录` `{旁路编号?,出站事件编号?,补录站点键,请求编号?}` | 经闸补录；被拒回 409 带拒绝明细 |
| `GET /api/补录账` | 补录审计流水 |

验收：`.venv/bin/python backend/tests/补录闸验收.py`（覆盖闸关拒绝、缺站拒绝、未知站拒绝、成对虚进、幂等、并发不双落、贯验对齐）。

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 刷卡点 | 带卡号/站点/方向/事件时的进出闸事件 |
| 开腿账 | 已进站尚未出站的在途开腿 |
| 行程账 | 进站+出站成对后的正式行程 |
| 旁路匣 | 缺腿超时 / 出站孤儿 / 重复进站等；出站孤儿带 状态=开/已补录 |
| 补录账 | 补录闸审计：闸态/旁路/虚进站/行程/结果/口径 |
| 行程贯验 | 成对刷卡 ↔ 行程笔数 ↔ 旁路命运互证 |
